# Planning notes: List the Cotton components a project can use

Suggestions from the maintainer for whoever builds this feature. The build answers each one by name.

## Look at django-cotton-gallery first

The annotation style our components use came from django-cotton-gallery, which reads it to show a gallery of components. It may have utility functions worth copying or using as inspiration for reading the annotations and for finding the components.

## Keep the output small

The main reader is a coding agent, and everything the command prints stays in its context for the rest of its session. The list should stay one short line per component, and the full documentation should appear only when asked for by name.
